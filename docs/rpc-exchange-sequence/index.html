↕
Ответ04 08 01 32 00

Префикс длины 04 одинаков. 2A — поле system_ping_request = 5, 32 — поле system_ping_response = 6.

01

RX/TX — со стороны Flipper

Android пишет в RX характеристику Flipper. Ответ Flipper отправляет через TX indications, которые принимает FlipperReceiver.

02

Framing ≠ BLE fragmentation

Префикс Varint обозначает длину PB.Main, а не BLE-пакета. Границы RX-записей и TX indications не обязаны совпадать с границами RPC-сообщения.

03

Иллюстративные BLE-границы

В сценарии фрагментации условно взят ATT MTU = 23 (20 байт данных на передачу). Реальное разбиение TX может отличаться; protobuf-байты и их длины точные для показанного примера.
